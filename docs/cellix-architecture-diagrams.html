8b. LLM Router — Priority Decision Tree

Priority: instant regex → data keywords → mode short-circuit → complexity classifier → LOW-tier LLM. File: llm-router.service.ts + complexity-classifier.util.ts

flowchart TD
    MSG[User message] --> INST{Instant shortcut regex?}
    INST -->|freeze/unfreeze/protect/zoom| SC[route = shortcut]
    INST -->|No| DATA{Data keyword fast lane?}
    DATA -->|find/sum/count/total…| DT[route = data]
    DATA -->|No| MODE{mode !== action?}
    MODE -->|Yes| ASK[route = ask]
    MODE -->|No| CX{classifyComplexity?}
    CX -->|tier 0–3| WR[route = write + complexity + actionHint]
    CX -->|miss| LLM[LOW-tier LLM JSON]
    LLM --> DECISION["route + optional complexity"]
    Note over DATA,DT: Data fast lane runs BEFORE mode short-circuit

19. Preview & Accept/Reject Pipeline

Structural + early cell writes apply on preview; Accept retries anything missed (SORT). Hard-deferred DELETE_SHEET only. Reject skips SORT cell-diff undo.

flowchart TD
    ACT[Actions from local or SSE] --> PART[partitionPreviewActions]
    PART --> STR[Structural: SORT_RANGE ADD_SHEET WRITE_TABLE…]
    PART --> EARLY[Early deferred: SET_CELL FORMAT…]
    PART --> HARD[Hard deferred: DELETE_SHEET]
    STR --> APPLY_NOW[ActionEngine on preview start]
    EARLY --> APPLY_NOW
    HARD --> WAIT[Held until Accept]
    APPLY_NOW --> BAR[PreviewSummaryBar + action card]
    WAIT --> BAR
    FAIL{Preview apply failed?}
    APPLY_NOW --> FAIL
    FAIL -->|Yes| RETRY[Accept still applies structural]
    FAIL -->|No| MARK[structuralApplied true]
    TIMELINE[Steps → thinking → AnswerReveal] --> READY{isTurnPresentationComplete?}
