# Cellix-2026

Workspace root for shared docs, specs, and `shared/` types. Application code is **not** in this repo.

Clone the three app repos into this same folder (they are gitignored here):

| Local folder | GitHub |
|---|---|
| `frontend/` | [usecellix/client](https://github.com/usecellix/client) |
| `cellix_backend/` | [usecellix/Server](https://github.com/usecellix/Server) |
| `Dashboard/` | [usecellix/Analytic-Dashboard](https://github.com/usecellix/Analytic-Dashboard) |

Start with `TASKS.md` for the sequenced backlog. Mark a task `🚧 In progress` (with your name) and push **before** you start it, then `✅ Done` when it lands, so everyone sees the same board.
